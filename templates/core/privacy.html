Privacy Policy

Last updated: October 2026

What we collect

  • Account data: email address, display name, phone number, and password hash.
  • Share metadata: encrypted file size, creation time, expiry, download count. Original filename and MIME type are inside the encrypted payload.
  • Guest identity: a pseudonymous signed cookie (hash only) to enforce daily share limits.
  • Billing: provider references, plan, status, and timestamps. No card numbers or CVV are stored.
  • Operational logs: errors and events without passphrases, passwords, or raw file content.

Encryption and server access

Files are encrypted in your browser using AES-256-GCM before upload. The passphrase never leaves your browser. The server stores only ciphertext and non-secret cryptographic parameters (salt, IV, algorithm version). AskMyFile servers cannot read your file contents.

We do observe metadata: encrypted file size, upload time, expiry, access events, and account/plan information. Client-side encryption does not hide this metadata.

Data retention and deletion

Encrypted payloads are deleted after link expiry or revocation. Guest identity hashes are retained for abuse-prevention purposes and are deleted after 30 days. You can request account deletion by contacting support.

Third-party providers

We use email, SMS, and payment providers to deliver verification messages and process subscriptions. Each provider receives only the minimum data needed for their function.

Guest quota limitations

Guest quotas are enforced per browser identity using a signed cookie and network-level signals. They are best-effort controls and cannot guarantee per-person enforcement if cookies are cleared or a different browser is used.

Security disclaimer

AskMyFile implements client-side encryption as described above. This application has not been independently audited as production-grade cryptographic software. Use appropriate judgment for sensitive data.
